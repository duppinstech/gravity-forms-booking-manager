# Bug fix

1. Read `memory/project-context.md` and the code path that produces the bug.
2. Write the expected behavior in one sentence before editing.
3. Fix the cause. Do not bundle a feature from `PLAN.md` into the same change.
4. Add a test or a manual case that fails before the fix and passes after it.
5. Run `workflows/department-review.md`. Security still reviews a one-line fix.
6. Note the bug and the fix in `memory/progress.md`.
