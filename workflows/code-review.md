# Code review

Engineering review of a diff. Department gates are `workflows/department-review.md`. This workflow does not replace them.

1. Read `rules/code-style.md`, `rules/api-conventions.md`, and `rules/testing-standard.md`.
2. Use `skills/code-review/SKILL.md`.
3. Check ownership: `Author` and copyright still say Duppins Technology / Odell Duppins.
4. Check booking rules stay on the server, not only in `assets/js/booking-manager.js`.
5. Return findings first, ordered by severity, using the skill's labels.

Then hand the same diff to `workflows/department-review.md`.
