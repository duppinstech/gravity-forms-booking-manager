# Security Policy

## Supported versions

Security fixes are provided for the latest release tagged on GitHub. Older versions may not receive patches.

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public GitHub issue with exploit details.

Report it by email to support@duppinstech.com, or through GitHub private vulnerability reporting:

https://github.com/oduppinsjr/gravity-forms-booking-manager/security/advisories/new

Include:

- Affected plugin version
- WordPress and Gravity Forms versions
- Impact (for example unauthorized booking changes, XSS, or CSRF)
- What you observed

Allow reasonable time for a fix before public disclosure.

## Scope

This plugin integrates with Gravity Forms and WordPress AJAX endpoints. Reports related only to Gravity Forms core or WordPress core should be directed to those projects unless this plugin introduces the vulnerability.

## Best practices for site owners

- Keep WordPress, Gravity Forms, and this plugin updated.
- Use HTTPS on production sites.
- Restrict form editing and the Bookings screen to trusted administrators.
