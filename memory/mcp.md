# MCP servers

`mcp.json` is shared through git. It currently has no servers.

Add a server here only when every developer on this plugin should have it, and only if the config contains no tokens, passwords, or personal paths. Put machine-specific servers and secrets in `CLAUDE.local.md` or the environment, not in this file.

Useful later, when you choose them: GitHub (releases and issues) and a WordPress or browser tool for form checks. Leave them out until you are ready to configure them.
