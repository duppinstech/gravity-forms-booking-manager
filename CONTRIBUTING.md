# Contributing

## Branches

Branch from `main`. Do not commit on `main`.

Name the branch `type/short-topic`:

- `feat/` for a booking behavior
- `fix/` for a defect
- `chore/` for docs, config, and repo hygiene

## Commits

Use a Conventional Commit subject: `type: why this changed`.

Types in use: `feat`, `fix`, `docs`, `chore`, `ci`.

One concern per commit. Do not commit `.env`, `CLAUDE.local.md`, `.claude/settings.local.json`, `local/`, or anything under `release/`.

## Pull requests

Open the pull request against `main`. Follow `.claude/rules/pr.md`.

- One sentence on the outcome, then what changed and how it was checked.
- Say "not run" when a check was not run.
- Author and copyright stay Odell Duppins / Duppins Technology.
- Do not add a price, support term, or legal promise.
